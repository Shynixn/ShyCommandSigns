
# ShyCommandSigns

ShyCommandSigns is a Minecraft server plugin that allows you to create interactive signs that execute commands when players click on them. It's designed for both Bukkit and Folia-based servers.

## Key Features

✨ **Interactive Signs**
* Create multiple clickable signs that execute customizable commands
* Support for both left and right-click actions
* Easy-to-use configuration system

🔧 **Technical Features**
* Full compatibility with Bukkit and Folia servers
* Integrated PlaceholderAPI support for dynamic content
* Asynchronous execution for optimal performance
* Extensive version support (1.8.R3 - 1.21.R7)
